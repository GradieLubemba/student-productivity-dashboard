# student-productivity-dashboard
## The Project
The Student Productivity Dashboard is a personal web development project designed to help students organize their academic tasks and manage their daily responsibilities.

The application allows students to add tasks, mark them as completed, delete tasks, and track their productivity.


## Features

- Add new academic tasks.
- Mark tasks as completed.
- Delete tasks.
- Track the total number of tasks.
- Display the number of completed tasks.
- Automatically save tasks using browser LocalStorage.
- Responsive design for different screen sizes.

## Technologies Used

- HTML5 – Structure of the application.
- CSS3 – Styling and responsive layout.
- JavaScript – Interactive functionality.
- LocalStorage – Saving tasks in the browser.
- GitHub – Project version control and documentation.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start adding and managing your academic tasks.
